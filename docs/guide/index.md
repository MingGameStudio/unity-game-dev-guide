# 阅读说明

欢迎来到《Unity 游戏开发入门指南》。

本书由 Ming 编写与维护，是小明工作室逐步整理课程内容与开发经验的在线书籍。

## 当前进度

网站已经搭建完成，正式章节正在准备。当前的第一章是写作占位页，不是已经完成的教学内容。

## 如何阅读

- 使用左侧目录选择章节；在手机上点击“全书目录”。
- 使用顶部搜索查找关键词。
- 页面底部可以前往上一页或下一页。
- 具体章节会注明使用的 Unity 版本、前置知识与所需素材。

## 如何反馈

发现错误或有建议时，可以通过仓库的 Issues 提交反馈。请说明页面名称、遇到的问题，以及能够帮助复现的步骤。
