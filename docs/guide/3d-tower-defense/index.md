# 第二部分：Unity 3D 游戏开发入门

用 Blender 制作美术资源，在 Unity 中制作一款 3D 塔防游戏。

## 学习目标

把自己制作的场景、敌人与防御塔组合成包含敌人路线、攻击与胜负流程的塔防游戏。

## 开始之前

具备基本 Unity 操作与简单脚本经验；Blender 从基础操作开始。

具体 Unity 版本、工具设置与所需素材将在正式章节中注明。
