## 学习目标

把自己制作的场景、敌人与防御塔组合成包含敌人路线、攻击与胜负流程的塔防游戏。

同时你应该不再满足于完全跟着这个课程所列出的步骤来做，而应该尝试加入自己的想法。有两种方式可以实现这个目标：
1. 在课程所提供的框架内加入改进和创新。
很多人喜欢无拘无束的创意过程。但实际上在一个商业项目里，更难能可贵的是如何在种种约束中，用创造性的手段来解决问题。例如我们觉得按照这个课程做出来的塔防游戏不好玩，学生会觉得我想要设计一个更好玩的游戏。这当然也是一个选项，下面就会说到。但更有挑战性的问题是，我要在现有的内容里加入什么玩法/机制上的改动，能够让它变得更好玩呢？
2. 开始根据自己的喜好来设计一个新的游戏。
这个选项很可能会打动很多学生，但是需要注意的是这个选项比想象中更难走。第一，也是最重要的，一定要从一个最小、最简单的想法开始。第二一定要学生承诺比之前的课程投入更多的时间和精力。其实在AI的帮助下，开发的难度已经不是最大的挑战。而是学生要意识到，开发游戏固然有趣，但“首先，这是一份工作” （李诞，脱口秀工作手册）如果不能做到这一点，就很难继续深入学习后面的内容了。

## 开始之前

具备基本 Unity 操作与简单脚本经验；Blender 从基础操作开始。
