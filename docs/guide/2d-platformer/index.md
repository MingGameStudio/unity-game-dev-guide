# 第一部分：Unity 2D 游戏开发入门

使用 Pixel Adventure 像素资源，制作一款 2D 平台跳跃游戏（Platformer）。

## 学习目标

完成包含角色移动、跳跃、机关、关卡切换与菜单的小游戏，并设计自己的关卡。

## 开始之前

面向初学者，从 Unity 编辑器与基础 C# 开始。

具体 Unity 版本、工具设置与所需素材将在正式章节中注明。
